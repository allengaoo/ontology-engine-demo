# miniGPT 配套说明（第 055 篇）

纯 C 实现的迷你 GPT：可编译、可训练、可推理。用来对照文章里「模型只在猜下一个符号」的说法。

## 文件

| 文件 | 说明 |
|------|------|
| `miniGPT.c` | 源代码（含解析反传与 AdamW） |
| `your.txt` | 示例训练文本（可换成你自己的 `.txt`） |
| `README.md` | 本说明 |

## 环境

- 一台能跑命令行的电脑（macOS / Linux / Windows + gcc 均可）
- 已安装 `gcc`

检查：

```bash
gcc --version
```

## 编译

把本压缩包解压后，在目录里执行：

```bash
gcc miniGPT.c -o miniGPT -lm -O2
```

## 训练

```bash
./miniGPT train your.txt
```

- 训练过程会打印 `loss`（随机猜大约 5.5，正常会降下来）
- 结束后生成 `weights.bin`（权重文件）

想更快跑通：打开 `miniGPT.c`，把 `CFG.max_iters` 改小（例如 `200`），重新编译再训。

## 推理（生成文字）

先完成训练，再执行：

```bash
./miniGPT generate "The "
```

提示词请放在引号里。演示版只输出常见可打印字符，避免终端乱码。

## 帮助

```bash
./miniGPT help
```

## 和文章的对应关系（读代码时看这些即可）

1. **因果掩码**：未来位置打成极低分，模型不能偷看后文  
2. **生成**：在概率里取更可能的下一个符号  
3. **训练三步**：`forward`（算损失）→ `backward`（回传误差）→ `optim_step`（改参数）  
4. 整份代码里**没有**业务规则表、权限校验、合同对象——那是决策系统其它层的事

## 默认规模（刻意做小）

- 2 层 Transformer  
- 向量维度 32  
- 注意力头 4  
- 上下文长度 32  
- 词表：256（按字节）

骨架和大厂语言模型同类，差在规模。

## 注意

- `weights.bin` 需自行训练生成，不随本包提供  
- 这是教学演示，续写质量远低于产品级模型；用途是看清机制，不是写小说
