# 前端演示步骤与验收清单

## 演示步骤

1. 打开浏览器，访问应用首页。
2. 点击“预约会议”按钮进入预约页面。
3. 在下拉框中选择一个会议室（确保是启用状态）。
4. 填写会议标题、预约人姓名。
5. 设置开始时间和结束时间（结束时间需晚于开始时间）。
6. 点击“提交预约”按钮。
7. 查看是否成功显示新创建的会议记录。

## 验收清单

- [ ] 页面加载正常，无报错信息。
- [ ] 会议室列表正确展示，包含名称、容量和状态。
- [ ] 只能选择处于激活状态的会议室。
- [ ] 提交表单时，如果必填项为空，则提示用户填写。
- [ ] 时间输入验证通过：结束时间必须晚于开始时间。
- [ ] 时间冲突检测有效：不能在已有会议时间段内预约。
- [ ] 成功创建会议后，页面更新显示新的会议条目。
- [ ] 错误处理机制完善：如网络异常或服务器错误时给出明确提示。
