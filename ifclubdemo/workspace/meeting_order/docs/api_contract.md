# API 接口文档

## 接口概览

所有接口均通过 `/api/v1` 前缀访问。

## 创建预约接口

### 路径
`POST /api/v1/bookings`

### 请求体 (CreateBookingRequest)
| 字段名     | 类型   | 必填 | 说明           |
|------------|--------|------|----------------|
| room_id    | int    | 是   | 会议室 ID      |
| title      | str    | 是   | 预约标题       |
| booker     | str    | 是   | 预约人姓名     |
| start_at   | str    | 是   | 开始时间 (ISO8601) |
| end_at     | str    | 是   | 结束时间 (ISO8601) |

### 成功响应 (BookingResponse)
| 字段名     | 类型   | 说明           |
|------------|--------|----------------|
| id         | int    | 预约记录 ID    |
| room_id    | int    | 会议室 ID      |
| title      | str    | 预约标题       |
| booker     | str    | 预约人姓名     |
| start_at   | str    | 开始时间       |
| end_at     | str    | 结束时间       |

### 错误响应
#### 时间无效
- 状态码: 400
- 内容: `{"detail": "结束时间必须晚于开始时间"}`

#### 会议室不存在或非激活状态
- 状态码: 400
- 内容: `{"detail": "所选会议室不存在或已被停用"}`

#### 时间冲突
- 状态码: 409
- 内容: `{"detail": "该时间段内已有预约，请选择其他时间"}`

#### 参数缺失
- 状态码: 422
- 内容: `{"detail": "请求参数不完整或格式错误"}`
